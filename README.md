Hey! I'm Neeraj. I enjoy building software from scratch — from programming languages and compilers to media engines and interactive 3D tools.

Most of my engineering time right now is dedicated to **[Rax](https://github.com/rax-language/rax)** (an open-source systems language built collaboratively through human-AI pair programming) and **[REC](https://github.com/pixlofficial/rec)** (a zero-copy hardware screen recording engine for Android).

---

### What I'm working on

- **[Rax](https://github.com/rax-language/rax)** — A self-hosted systems programming language with clean indented syntax, deterministic ARC memory safety, and universal direct machine code emission (x86-64, ARM64, PE32+).
- **[REC](https://github.com/pixlofficial/rec)** — Zero-copy, hardware-accelerated screen recording and RTMP live-streaming engine for Android built with Kotlin, Jetpack Compose, NDK, and MediaCodec.
- **[3D Spatial Workstation](https://neerajm.vercel.app)** — Interactive 3D workspace built with Three.js, React 19, and custom WebGL shaders.
