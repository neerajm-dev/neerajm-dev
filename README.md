### 🚀 Featured Engineering

#### 01. [Rax Programming Language](https://github.com/rax-language/rax)
> *A self-hosted systems programming language with clean indented syntax, deterministic ARC memory safety, and native machine performance.*

`Language: Pure Rax (.rax)` &bull; `Bootstrap: Standalone C11 (<1s)` &bull; `Emission: Direct ELF64 / Mach-O / PE32+`

- **Multi-Stage Self-Hosting**: Built from a pure C11 bootstrap compiler compiling a Stage 1/2 self-hosted compiler written in pure Rax.
- **Universal Direct Machine Code**: Custom Tier 3 machine code generator emitting standalone binaries with zero external dependencies in ~75 &micro;s.
- **Deterministic Memory Safety**: Compile-time escape analysis and zero-cost stack promotion backed by deterministic Automatic Reference Counting (0 GC).
- **Formal Verification**: First-class struct invariants and native Meyer Design-by-Contract (`requires`, `ensures`, `old`, `result`).

---

#### 02. [REC &bull; Hardware Media & Recording Engine](https://github.com/pixlofficial/rec)
> *Zero-copy, hardware-accelerated screen recording and RTMP live-streaming engine for Android.*

`Stack: Kotlin` &bull; `Jetpack Compose` &bull; `MediaCodec / NDK` &bull; `AHardwareBuffer` &bull; `OpenGL ES` &bull; `RTMP`

- **Zero-Copy Surface Pipeline**: Pipes GPU display frames directly into silicon ASIC hardware encoders via `MediaProjection` &rarr; `VirtualDisplay` &rarr; `MediaCodec` Input Surface, sustaining 120+ FPS at <5% CPU usage.
- **Dual-Stream Audio Engine**: Concurrently captures internal audio and microphone commentary with a custom 16-bit 48 kHz PCM mixer and a Padé [3/3] rational polynomial soft-knee limiter.
- **Instant Replay Buffer**: Volatile RAM rolling ring buffer (15s–120s) with GOP-aware keyframe preservation and non-blocking background MP4 clip export.
- **Live Broadcast Studio**: Client-to-server RTMP/RTMPS streaming with Adaptive Bitrate (ABR) and hardware-backed `AndroidKeyStore` AES-GCM credential security.
