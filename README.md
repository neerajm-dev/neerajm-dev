# Neeraj M

Hey! I'm Neeraj. I like building software from scratch — from programming languages and compilers to web platforms and distributed tools.

Most of my time right now is spent building **[Rax](https://github.com/rax-language/rax)**, an open-source systems programming language developed collaboratively through human-AI pair programming.

---

### What I'm Building

- **[Rax Programming Language](https://github.com/rax-language/rax)**  
  A self-hosted systems programming language with clean indented syntax, deterministic ARC memory safety, and native machine performance.
  - Built from an auditable, zero-dependency C11 bootstrap compiler.
  - Multi-tier pipeline: fast development runtime, unboxed AOT native backend, and direct ELF64 / Mach-O / PE32+ machine code emission.
  - Native formal contracts (`requires`, `ensures`) and first-class struct invariants.

- **[KTCC Platform](https://ktccofficial.vercel.app)**  
  A real-time tournament management and competition platform built for mobile gaming communities.
  - Full-stack Next.js and Supabase architecture with live updates, idempotent point ledger, and edge asset delivery.

- **[3D Spatial Workstation](https://neerajm.vercel.app)**  
  An interactive 3D developer workspace built with Three.js and WebGL shaders.
